Sobre o Projeto

A Estação de Monitoramento IoT é um projeto desenvolvido para acompanhar informações ambientais em tempo real. O sistema utiliza um ESP32 conectado a sensores para realizar a coleta dos dados.

Os dados de temperatura, umidade e qualidade do ar são enviados por meio do protocolo MQTT para o servidor Mosquitto e apresentados em um Dashboard Web.

Hardware Utilizado

ESP32

O ESP32 é o microcontrolador responsável pela leitura dos sensores e pelo envio dos dados através da rede Wi-Fi.

Sensores

O DHT11 realiza a medição da temperatura e da umidade. O MQ-135 é utilizado para acompanhar a qualidade do ar.

LEDs de Alerta

Os LEDs indicam quando os valores dos sensores ultrapassam os limites definidos no projeto.

Arquitetura do Projeto

O ESP32 coleta os dados dos sensores e envia as informações para o broker Mosquitto utilizando o protocolo MQTT.

O Dashboard Web recebe essas informações através de WebSockets e atualiza os valores apresentados na tela em tempo real.

ESP32 → Sensores → Wi-Fi → Mosquitto → WebSocket → Dashboard

Limites de Alerta

  • Temperatura acima de 28°C
  • Umidade acima de 56%
  • Qualidade do ar acima de 400
