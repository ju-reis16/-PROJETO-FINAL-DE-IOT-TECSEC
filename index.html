Sobre o Projeto

O Estação de Monitoramento IoT é um projeto de Internet das Coisas desenvolvido para monitorar informações ambientais em tempo real. Através de sensores, o sistema coleta dados como temperatura e umidade e envia essas informações para um dashboard web. Assim, é possível acompanhar as condições do ambiente de forma prática, rápida e organizada.

ESP32

O ESP32 é o microcontrolador responsável por receber os dados dos sensores, processar as informações e enviá-las para o broker MQTT através da rede Wi-Fi.

Sensores

O sensor DHT11 realiza a medição da temperatura e umidade. O sensor MQ-135 é utilizado para realizar a leitura relacionada à qualidade do ar.

MQTT

O MQTT é o protocolo utilizado para comunicação entre o ESP32 e o Dashboard. O Mosquitto funciona como broker, recebendo e distribuindo as mensagens.

Arquitetura do Projeto

O funcionamento começa nos sensores, que realizam as medições. O ESP32 recebe essas informações e publica os valores nos tópicos MQTT. O broker Mosquitto recebe as mensagens e o Dashboard Web, conectado através de WebSockets, recebe os dados e atualiza os valores na tela em tempo real.
